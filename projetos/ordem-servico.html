O que o Ordem de Serviço faz

Troca a planilha de OS por um sistema com papéis, verificação obrigatória e trilha para auditoria.

01

Abre a OS com equipamento e prioridade

A TAG do equipamento, o tipo de manutenção e se a linha está parada.

02

Separa quem executa de quem verifica

A manutenção registra o serviço; outra pessoa confere limpeza e libera a linha.

03

Guarda a trilha para auditoria

Cada mudança de status fica gravada com usuário e horário.

Decisões técnicas

  • Cadastro novo fica pendente até o admin aprovar e definir o papel.
  • Login e usuários saíram do localStorage para uma API própria com banco.
  • A OS só fecha depois da verificação assinada.
  • O status anda numa ordem fixa: aberta, execução, verificação, fechada.

O banco, migração por migração

Aplique as migrações na ordem em que o banco foi criado. O código é MySQL e roda num SQLite dentro do seu navegador; os dados de exemplo são fictícios.
