DEVFOOD DATABASE.

Banco de dados completo de uma plataforma de delivery, criado do zero para mostrar modelagem, integridade, automação e análise de dados. Monte o banco migração por migração, veja as tabelas surgirem e rode consultas de verdade aqui mesmo.

MODELAGEM

O QUE ESTE BANCO DEMONSTRA.

Cada decisão está no código das migrações abaixo, com o motivo de cada passo.

Modelagem normalizada

Clientes, endereços, restaurantes, cardápio, pedidos, pagamentos e entregas em 3ª forma normal, sem dado repetido.

3FNChaves estrangeiras

Integridade no banco

CHECK, UNIQUE composto e um índice parcial que impede dois endereços principais para o mesmo cliente.

CHECKÍndice parcial

Regras automáticas

Triggers somam o subtotal, travam pedido finalizado e guardam o histórico de status e de preço. O total é coluna calculada.

TriggersGenerated column

Performance

Índices compostos pensados para as telas mais usadas, conferidos com o plano de execução da consulta.

ÍndicesEXPLAIN

Análise de dados

Views para o painel, faturamento acumulado, ranking de produtos e quartis de clientes com funções de janela.

CTEWindow functions

Dados gerados por SQL

Uma CTE recursiva cria 60 dias de pedidos no almoço e no jantar, e o ciclo de vida de cada um passa pelos triggers.
