O que o Premiatta Connect faz

Cada login vê a própria tabela de preço, monta o pedido no simulador e envia para o ERP Ti9.

01

Mostra o preço certo para cada login

O usuário aponta para uma tabela de preço; o simulador só lista os preços dela.

02

Calcula total e peso do pedido

Quantidade por produto, subtotal, peso da carga e condição de pagamento antes de enviar.

03

Envia o pedido ao ERP

O pedido vai para a API AFV do Ti9 e o número devolvido fica gravado junto dele.

Decisões técnicas

  • O preço é gravado no item do pedido, então uma tabela nova não altera pedidos antigos.
  • O código de cada produto é o mesmo do Ti9, sem tabela de tradução.
  • Toda chamada à API fica num log com a resposta, para achar falhas de envio.
  • O perfil é checado no PHP em cada tela, não só no JavaScript.

O banco, migração por migração

Aplique as migrações na ordem em que o banco foi criado. O código é MySQL e roda num SQLite dentro do seu navegador; os dados de exemplo são fictícios.
