Como um projeto anda

Quatro etapas, com algo funcionando para você testar ao fim de cada uma.

01

Conversa e escopo

Entendo o processo de hoje, muitas vezes uma planilha, e listo o que o sistema precisa fazer.

02

Modelo do banco

Desenho tabelas e relações antes da primeira tela. É a decisão que mais muda o resto.

03

Telas e API

Interface em HTML, CSS e JavaScript falando com uma API em PHP ou Node.

04

Publicação e ajustes

Coloco no ar na Hostinger ou na Vercel e sigo ajustando com quem usa.
